## LinkedIn (feed post)

Stop downloading files just so you can upload them to Dropbox.

That loop — right-click → Downloads → Finder → Dropbox — is quiet workflow debt. Designers, researchers, and content people pay it dozens of times a week.

I built **Web Saver for Dropbox** to cut it.

- Right-click an image, PDF, or file link → save straight into your Dropbox folder
- Or scan the page, tick several assets, and save them in one go
- Free. MIT open source. Chrome, Brave, Edge
- You connect *your* Dropbox app once (~3 minutes). App key and tokens stay in your browser. There is no Web Saver server

The setup that feels “extra” is the privacy product: you are not handing Dropbox access to a middleman’s backend.

Honest limits: Chromium-only for now. Streamed / blob video is not the job this tool solves.

If you already live in Dropbox, install it:
https://chromewebstore.google.com/detail/web-saver-for-dropbox/hpgokiookclncalkhobnlpcgfnafjhbi

Source: https://github.com/oyerohabib/dropbox-web-saver
